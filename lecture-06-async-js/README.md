# Lecture 05 - DOM, State & Browser API

## Features implemented

1. **Dynamic sections (DOM)** -- Skills and Projects sections are created entirely in JavaScript using `createElement` and `appendChild`. No hardcoded HTML for these sections.
2. **Theme toggle with persistence (State + localStorage)** -- A toggle button switches between light/dark mode. The choice is saved to `localStorage` and restored automatically on page load.

## How to test

- **Skills & Projects**: Open the page -- the Skills (pill-shaped list) and Projects (two cards with links) sections appear below Interests. They are generated by `script.js`.
- **Theme toggle**: Click the "Toggle Theme" button in the header. The page switches to dark mode. Reload the page -- the theme is preserved.
- **Last updated**: Scroll to the bottom of the page -- a "Last updated: YYYY-MM-DD" line is generated automatically by JavaScript.
